- FIRESENSE 화재 3개·비화재 3개를 고정하고, 실제 모델로 총 1,508프레임을 처리했습니다.

- 설정 유지·실행값 기록을 수정하고 자동화 테스트 27개 통과 후 동일 입력으로 재실행했습니다.
- 최종 6개 run 모두 실제 CPU 스레드 4개, 입력 640×640, 깨끗한 Git 상태를 확인했습니다.
- 최종 합산 파일 처리 속도는 11.61 FPS, 모델 호출 평균은 83.79 ms였습니다.

- 초기 실행과 최종 실행을 별도 폴더로 보관하고, 원본·가중치·원시 결과는 Git에서 제외합니다.
- 검토 이미지·요약은 `outputs/001_firesense_baseline/`, 주석 영상은 각 `experiments/runs/`에 있습니다.

상세 결과: [FIRESENSE CPU 기준 실험](../reports/001_firesense_baseline.md).

## 2026-10-29 — 가상환경 검증

- 기존 `.venv`에 Python 3.11.9와 지정된 CPU 라이브러리가 설치되어 있음을 확인했습니다.
- `setup.ps1 -SkipModel`을 다시 실행하여 의존성과 자동화 테스트 24개 통과를 확인했습니다.
- 시스템·사용자 site-packages가 분리되어 있고, 주요 패키지는 모두 `.venv`에서 import됩니다.
- VS Code 로컬 설정에 `.venv`를 기본 인터프리터 경로로 지정했습니다.
  기존에 선택한 인터프리터가 있으면 `Python: Select Interpreter`에서 직접 선택해야 합니다.
- 프로젝트 실행·설치는 `.venv`를 사용하도록 작업 규칙과 사용 안내를 정리했습니다.
  초기 커밋 스크립트도 `.venv`가 없으면 시스템 Python으로 대체하지 않고 중단합니다.
- 이미 존재하는 모델 파일의 SHA256은 확인했습니다. 이번 작업에서 실제 화재 추론은 수행하지 않았습니다.
- 기존 Git 쓰기·네트워크 제한은 현재 세션에서 해제되었으며, 초기 커밋 3개가 원격에 있음을 확인했습니다.

상세 결과: [가상환경 검증](../reports/000_venv_setup.md).

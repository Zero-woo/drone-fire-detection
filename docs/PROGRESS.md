- 기존 `.venv`에 Python 3.11.9와 지정된 CPU 라이브러리가 설치되어 있음을 확인했습니다.

  기존에 선택한 인터프리터가 있으면 `Python: Select Interpreter`에서 직접 선택해야 합니다.
- 프로젝트 실행·설치는 `.venv`를 사용하도록 작업 규칙과 사용 안내를 정리했습니다.

- 이미 존재하는 모델 파일의 SHA256은 확인했습니다. 이번 작업에서 실제 화재 추론은 수행하지 않았습니다.
- 기존 Git 쓰기·네트워크 제한은 현재 세션에서 해제되었으며, 초기 커밋 3개가 원격에 있음을 확인했습니다.

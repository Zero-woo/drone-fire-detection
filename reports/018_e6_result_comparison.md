## 화재·연기와 오탐

E1→E6에서 화재 TP는 1554→1562, FN은 600→592, FP는 914→891이다. 화재 Recall은 72.14→72.52%, Precision은 62.97→63.68%로 개선됐다. E4 대비 Recall은 +1.300%p다.

정상 이미지의 오탐은 E1 26장→E6 28장으로 2장 증가했고 E4 34장→E6 28장으로 6장 줄었다. 정상 이미지에 한정한 집계와 전체 이미지의 화재 FP 집계를 구분해 해석한다.

연기 Recall은 E1 82.53→E6 82.95%이며, Precision은 78.42→76.78%다. 연기 FP는 429→474로 늘었다. 클래스별 AP50-95는 화재 37.76→38.47%, 연기 52.56→52.96%다.

## 학습 시간과 선택 체크포인트

- E6 학습 시작은 2026-11-06T15:43:02.495252+09:00이며 종료는 2026-11-07T07:13:16.326649+09:00다.
- 순수 기록 학습 시간은 15시간 30분 14초, 공통 Validation은 0시간 15분 19초다. 무결성 검증과 보고를 거쳐 오전 7시 30분에 큐가 종료됐다.
- 학습 내부 Validation의 최고 epoch는 79이며 해당 best.pt를 공통 Validation에 사용했다. 내부 mAP50-95 0.46706, 마지막 epoch 0.46591은 학습 중 평가 설정에서 얻은 수치다. 실험 간 비교 표는 공통 Validation의 0.45714를 사용한다.
- E1 학습은 10시간 38분 8초, E4는 9시간 19분 52초였다. E6의 학습 시간은 E1의 1.46배다.
- 같은 서버의 batch 1/FP32 추론은 E1 5.16ms/장, E6 6.04ms/장으로 약 17.2% 증가했다. 전처리·NMS를 포함한 측정 파이프라인은 6.98→8.69ms/장이다.

주 지표인 mAP 기준으로 E6가 선두이고 화재 지표도 개선됐다. 정상 오탐, 연기 Precision, 학습·추론 비용에는 위 차이가 있다. 각 조건은 seed 42 한 번의 관측이며 seed별 변동은 후속 검증 항목이다. 현재 큐 상태는 최종 모델과 threshold 선택 대기다.

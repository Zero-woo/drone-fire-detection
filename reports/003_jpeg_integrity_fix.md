# D-Fire 입력 JPEG 무결성 보정 기록

GPU 서버 실험에서 사용하는 `dfire-fold1-v2` 입력의 준비와 무결성 정책을 기록한다. 보정 구현 시점은 2026-10-31이며 구현 commit은 `6c4387a`다.

## JPEG 보정 방법

일부 원본 JPEG는 종료 마커 `FF D9` 뒤에 부가 바이트를 포함했다. Ultralytics 8.4.0의 JPEG verifier가 이를 재저장하면 입력 SHA256이 바뀌므로 파생 입력에서 종료 마커 뒤 부가 바이트를 제거하는 정책을 적용했다.

- 해당 형식의 이미지 37개를 확인했다.
- 부가 바이트를 제거한 뒤 RGB 크기와 픽셀이 원본과 같은지 확인했다.
- 이미지·라벨·분할 목록의 SHA256과 데이터 fingerprint를 manifest에 기록했다.
- 원본 이미지 21,527개와 label 21,527개의 해시를 확인했다.
- 학습 loader 준비 후와 학습·평가 종료 시 입력 해시를 검사한다.

데이터 fingerprint는 `c3d63dfa73314a36b5522f4651f5fd7d784bd8a054e78916f821160729862e2b`다. Train 13,776장 / Validation 3,445장 / Test 4,306장의 공식 fold 1 분할을 사용한다.

## 검증 근거

보정된 JPEG 37개의 설치된 verifier 검사, 원본 해시 일치, 변경 이미지와 수정 전후 바이트 수를 동명 JSON에 보존했다. 이 항목은 서버 학습 입력의 데이터 정합성 근거다. [데이터 감사 JSON](003_jpeg_integrity_fix.json)

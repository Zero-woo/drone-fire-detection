2026-11-06(KST) 사용자가 E6 자동 실행을 승인했다. 이 문서는 설정 선택과 이관 준비 기록이며 실제 E6 학습 완료 결과가 아니다.

- 선택: imgsz 800 / 100 epochs / patience 0 / lr0 0.01 / MuSGD / batch 16 / seed 42 / FP32 / 기본 HSV / mosaic 1.0.
- 시작 모델은 SHA256이 고정된 COCO yolov8n.pt다. 완료된 E1/E4의 가중치를 이어 학습하지 않는다.
- E4-800은 공통 mAP50-95 0.45234로 가장 높았지만 E1 대비 +0.074%p의 작은 차이이며, Fire Recall 0.71216 및 정상 오탐 34장은 E1의 0.72145/26장보다 불리했다.
- E1과 같은 100 epoch/patience 0 조건에서 800 후보의 이득과 손실을 검증한다. E1은 비교 기준과 최종 선택 대안으로 보존한다.
- 학습률·HSV·Mosaic 변경은 뚜렷한 이득이 없어 기본값을 유지한다. E5와 반복 seed는 이번 큐에 추가하지 않는다.

기존 핵심 큐는 전부 완료됐고 관리자·작업자가 종료됐음을 확인했다. 코드/설정 변경 전에 기존 계획·상태·16개 고정 소스/설정·완료 보고서를 work/e6-migration_20261106T060752Z_927ed3dc/에 보존했다. 기존 계획, COCO, 전체 입력 및 완료 모델/평가 연결 검증을 통과했다.

새 이관 명령은 보존본 SHA256과 기존 상태의 일치를 검사한 뒤 E6 작업만 추가해야 한다. 기존 E1~E4 run/설정/완료 상태를 유지하고, 새 계획에는 원래 계획·상태·보존본 digest와 Validation 선택 근거를 연결한다. 관리자/작업자 생존, 기존 E6 run, 체크섬 오류는 중복 실행을 거부한다.

자동 흐름은 E6 학습 → 완료/무결성 검증 → best.pt 공통 Validation → 비교 보고 → 최종 선택 대기다. OOM/무결성 오류는 실패로 보존하고 자동 조건 변경이나 재시도를 하지 않는다. 모델/threshold 동결과 실제 Test는 자동 수행하지 않는다.

선택 근거의 원본 기록 SHA256, 모델/입력 SHA256, 보존 계획 digest와 구체적인 인자는 [JSON](016_e6_queue_preparation.json)에 기록했다.

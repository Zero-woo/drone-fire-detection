# 실험 로드맵

| 단계 | 목표 | 완료 판단 | 상태 |
|---|---|---|---|
| 000 | 저장소·환경·기록 체계 | 구조, 오프라인 검증, 설치 안내 | 준비/검증 |
| 001 | 공개 모델 CPU 기준 실험 | 실제 사진·영상 추론과 시간 기록 | 설치·입력 대기 |
| 002 | 모델·해상도 비교 | 같은 독립 시험 영상으로 오탐·누락·속도 비교 | 계획 |
| 003 | 실시간 영상 + 반복 확인 | 최신 프레임, 끊김 무효화, 지연 측정 | 계획 |
| 004 | 필요한 경우 추가 학습 | 촬영 세션별 데이터 분리와 동일 시험 비교 | 선택 |
| 005 | FC/투하 판단 연결 | 별도 통신·동작 시험 | 추후 |

1. 실행 전 가설·설정·입력을 정합니다.
2. 실행별 고유 폴더에 원본 결과를 보관하고 검토한 보고서를 Git에 커밋합니다.
3. 변경한 코드 검증 후 커밋하며 정식 비교 실행은 깨끗한 커밋에서 합니다.
4. `git_dirty: true` 실행은 미커밋 코드가 있었다는 뜻입니다.
5. 합성 테스트를 실제 탐지 성능으로 표시하지 않습니다.
6. 모델 학습 데이터와 겹치는 예시는 설치 확인에만 사용하고 독립 평가로 주장하지 않습니다.
